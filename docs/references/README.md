# Visual reference inventory

The initial interface research reviewed common public banking patterns such as audience navigation, product grouping, sign-in and recovery controls, promotional sections, card-based product discovery, support resources and deep footer navigation.

Chaze Bank uses that structural research with original copy, original generated photography, original line icons, a distinct wordmark and centralized design tokens. No external private or authenticated banking interface was accessed, and no third-party bank logo or proprietary asset is part of the product.
